# PIM — управление товарной информацией

Headless PIM для интернет-магазина на Django: товары, бренды, категории
(с вложенностью), характеристики (5 типов, привязка к категориям) и
PDF-документы. Управление через админку, отдача каталога во внешний JSON-API.

## Статус

- [x] Этап 1 — модель данных и каркас проекта
- [x] Этап 2 — админка (CRUD по всем сущностям)
- [x] Этап 3 — динамическая форма категорийных характеристик + транслитерация
- [x] Этап 4 — JSON-API каталога (публичное чтение, запись по токену)
- [x] Этап 5 — деплой на VPS (gunicorn + nginx + PostgreSQL, автодеплой из GitHub Actions)

## Быстрый старт (локально)

См. [SETUP.md](SETUP.md). Коротко: venv → `pip install -r requirements.txt`
→ `migrate` → `createsuperuser` → `runserver` → http://127.0.0.1:8000/admin/

## Рабочий процесс

Разработка локально → коммит и `push` в `main` на GitHub → деплой на VPS.
Развёртывание и автодеплой описаны в [DEPLOY.md](DEPLOY.md).

Через git едут **только код и миграции**. Базы данных и загруженные файлы
(`media/`) у каждой среды свои: локально — SQLite, на проде — PostgreSQL.
Схему на проде разворачивает `python manage.py migrate` из закоммиченных
файлов миграций. Секреты — в `.env` (в репозиторий не коммитятся).

## Стек

Python 3.12+, Django 5.2 LTS, Pillow, django-tinymce (визуальный редактор),
django-admin-sortable2 (drag-and-drop). На продакшене дополнительно:
PostgreSQL, gunicorn, nginx, HTTPS (Let's Encrypt).
